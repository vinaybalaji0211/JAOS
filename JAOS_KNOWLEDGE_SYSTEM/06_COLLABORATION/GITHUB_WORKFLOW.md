\# Purpose



This document defines how JAOS uses GitHub for collaboration, version control, milestones, and future team development.



\---



\# Repository Role



GitHub is the collaboration platform.



The repository stores:



\- source code

\- tests

\- documentation

\- Knowledge System

\- project history



\---



\# Branch Strategy



\## Current Solo Development



During solo Alpha development, work may continue directly on main if the repository remains stable.



\## Future Team Development



When collaborators join:



\- main must remain stable

\- feature branches must be used

\- pull requests must be reviewed

\- tests must pass before merge
