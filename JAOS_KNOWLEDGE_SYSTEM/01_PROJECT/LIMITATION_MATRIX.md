\# Hardware Awareness



JAOS must adapt to available hardware.



Examples:



\- Available RAM

\- CPU

\- GPU

\- Storage

\- Internet availability

\- Installed AI models



If resources are limited, JAOS should adjust its behavior instead of failing.



\---



\# Transparency Rule



JAOS must never claim to support a feature unless:



\- it is implemented,

\- tested,

\- and verified.



If a feature is planned, JAOS should clearly identify it as planned.
