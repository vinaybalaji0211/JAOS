\# JAOS First Day Guide



Welcome to JAOS.



Before writing code:



1\. Read the JAOS Vision.

2\. Read the Architecture Principles.

3\. Read the Coding Standards.

4\. Read the Development Workflow.

5\. Understand the current roadmap.



\---



\## Setup



Clone the repository.



Install dependencies.



Create the virtual environment.



Run all tests.



Verify the project builds successfully.



\---



\## First Contribution



Do not begin with a major feature.



Start with:



\- Documentation

\- Small bug fixes

\- Unit tests

\- Minor improvements



Learn the architecture before implementing major components.
