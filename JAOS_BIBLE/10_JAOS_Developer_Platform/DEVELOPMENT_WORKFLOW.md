\# JAOS Development Workflow



Every feature developed for JAOS follows the same lifecycle.



\---



Idea



↓



Architecture Discussion



↓



Architecture Review



↓



Implementation



↓



Unit Testing



↓



Integration Testing



↓



Documentation



↓



Code Review



↓



Merge



↓



Architecture Certification



\---



\## Rules



Never skip testing.



Never skip documentation.



Never merge code without review.



Never bypass architecture decisions.



Always update the JAOS Bible if the architecture changes.



\---



\## Daily Workflow



1\. Pull latest changes.

2\. Read assigned task.

3\. Review architecture impact.

4\. Implement feature.

5\. Run tests.

6\. Update documentation.

7\. Commit changes.

8\. Submit Pull Request.
