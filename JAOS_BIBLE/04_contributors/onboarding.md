\# JAOS Contributor Onboarding Guide



\## Purpose



This guide explains how a new contributor should join the JAOS project.



JAOS is not just an AI assistant. It is an AI Operating System. Every contributor must understand the architecture before writing production code.



\---



\## Before Writing Code



A new contributor must read:



1\. JAOS Vision

2\. Architecture Principles

3\. Python Coding Standards

4\. Git Workflow

5\. Code Review Checklist

6\. Architecture Review Checklist



\---



\## Contributor Setup



Each contributor must work on their own computer.



No contributor should directly edit another person's local project folder.



The project should be shared using GitHub or another Git-based platform.



\---



\## Required Tools



Recommended tools:



\- Git

\- GitHub account

\- Python

\- Conda or virtual environment

\- VS Code

\- Terminal / Command Prompt



\---



\## First Task Rule



A new contributor should not start with a major feature.



Their first task should be small, such as:



\- documentation update

\- simple bug fix

\- unit test

\- small isolated module



This allows them to learn the architecture safely.



\---



\## Main Rule



Do not break the architecture to finish a task faster.
