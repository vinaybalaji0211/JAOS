\# Contributing to JAOS



Thank you for contributing to JAOS.



JAOS is an AI Operating System project. Contributors must respect the architecture, documentation, and testing process.



\## Before Contributing



Read:



\- JAOS Engineering Handbook

\- Architecture Principles

\- Coding Standards

\- Git Workflow

\- Definition of Done



\## Contribution Rules



\- Do not push unstable code to main.

\- Create a feature branch.

\- Run tests before submitting changes.

\- Update documentation when needed.

\- Follow the JAOS Constitution.

\- Do not bypass permissions or security design.



\## Development Flow



1\. Pull latest code.

2\. Create feature branch.

3\. Implement change.

4\. Run tests.

5\. Update documentation.

6\. Submit Pull Request.

7\. Wait for review.

8\. Merge only after approval.



\## First Contribution



Start small:



\- Documentation improvement

\- Unit test

\- Small bug fix

\- Isolated module improvement
