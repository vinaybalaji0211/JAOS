\# JAOS Code of Conduct



JAOS contributors should maintain a respectful, professional, and learning-focused environment.



\## Expected Behavior



\- Be respectful.

\- Review code constructively.

\- Explain decisions clearly.

\- Protect the architecture.

\- Help contributors learn.

\- Keep discussions focused on the project.



\## Unacceptable Behavior



\- Disrespectful communication

\- Careless changes to critical architecture

\- Ignoring review process

\- Bypassing safety rules

\- Committing secrets or unsafe code



\## Project Principle



Knowledge belongs to the project, not individuals.
