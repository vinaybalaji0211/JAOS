\# JAOS Security Policy



Security is a core principle of JAOS.



\## Security Rules



\- Sensitive actions require user approval.

\- JAOS must not bypass the Permission Gateway.

\- Secrets must never be committed.

\- API keys must stay outside source code.

\- Critical system actions must be logged.

\- Automation must be explainable.



\## Sensitive Actions



Examples:



\- Deleting files

\- Sending emails

\- Modifying system settings

\- Accessing private data

\- Installing software

\- Running external commands



\## Reporting Security Issues



Report security concerns directly to the project owner.
